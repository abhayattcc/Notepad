Kids Notepad Help Guide

English
हिंदी
ଓଡ଼ିଆ

Text Writing Section (Write Tab)

  • Undo: Revert the last text change.
  • Redo: Redo the last undone action.
  • Find & Replace: Search for text and replace it.
  • Select All: Select entire text.
  • Copy: Copy selected text to clipboard.
  • Erase Text: Clear all text.
  • Save Text: Save current text with a unique ID.
  • Saved Texts: View and load saved texts.
  • Delete Saved: Move saved text to trash.
  • Restore Text: Restore from trash (within 60 days).
  • Perm Delete: Permanently delete from trash.
  • Open File: Load TXT or PDF (text extract or draw mode).
  • Export Text: Download current text as TXT.
  • Support Us: Donate via UPI.

Drawing Section (Draw Tab)

  • Draw: Toggle drawing mode (smooth curves).
  • Eraser: Toggle eraser (right-click or 2-finger touch).
  • Bucket Fill: Fill areas with selected color.
  • Lock View: Lock drawing (5-finger touch toggle).
  • Reset Pos: Reset canvas position.
  • New Page: Add a new drawing page.
  • Clear Page: Clear current page (removes empty pages).
  • Undo/Redo: Undo/redo drawing actions.
  • Save JPG: Export current page as JPG.
  • Share PDF: Export all pages as PDF.
  • Pen Width: Select line thickness.
  • Pen Color: Select color from dropdown or picker.
  • Page Controls: Navigate pages (swipe in lock mode).
  • Multi-Touch: 1-finger: draw; 2-finger: erase; 3-finger: undo; 4-finger: random color.

General

  • Switch tabs to alternate between text and drawing.
  • Collapse sections by tapping the active tab again.
  • Data saved automatically in browser storage.

पाठ लेखन अनुभाग (लिखें टैब)

  • पूर्ववत: अंतिम पाठ परिवर्तन को पूर्ववत करें।
  • पुनः करें: अंतिम पूर्ववत क्रिया को दोहराएं।
  • खोजें और बदलें: पाठ खोजें और बदलें।
  • सभी चुनें: पूरा पाठ चुनें।
  • कॉपी: चयनित पाठ को क्लिपबोर्ड पर कॉपी करें।
  • पाठ मिटाएं: सभी पाठ साफ करें।
  • पाठ सहेजें: वर्तमान पाठ को अद्वितीय आईडी के साथ सहेजें।
  • सहेजे गए पाठ: सहेजे गए पाठ देखें और लोड करें।
  • सहेजा गया हटाएं: सहेजे गए पाठ को कचरे में ले जाएं।
  • पाठ पुनर्स्थापित करें: कचरे से पुनर्स्थापित करें (60 दिनों के अंदर)।
  • स्थायी हटाएं: कचरे से स्थायी रूप से हटाएं।
  • फ़ाइल खोलें: TXT या PDF लोड करें (पाठ निकालें या ड्रॉ मोड)।
  • पाठ निर्यात करें: वर्तमान पाठ को TXT के रूप में डाउनलोड करें।
  • हमारा समर्थन करें: UPI के माध्यम से दान करें।

ड्राइंग अनुभाग (ड्रॉ टैब)

  • ड्रॉ: ड्राइंग मोड टॉगल करें (स्मूथ कर्व्स)।
  • रबर: रबर टॉगल करें (राइट-क्लिक या 2-उंगली टच)।
  • बकेट फिल: क्षेत्रों को चयनित रंग से भरें।
  • लॉक व्यू: ड्राइंग लॉक करें (5-उंगली टच टॉगल)।
  • रीसेट पोज: कैनवास स्थिति रीसेट करें।
  • नया पेज: नया ड्राइंग पेज जोड़ें।
  • पेज साफ करें: वर्तमान पेज साफ करें (खाली पेज हटाएं)।
  • पूर्ववत/पुनः करें: ड्राइंग क्रियाओं को पूर्ववत/दोहराएं।
  • JPG सहेजें: वर्तमान पेज को JPG के रूप में निर्यात करें।
  • PDF शेयर करें: सभी पेजों को PDF के रूप में निर्यात करें।
  • पेन चौड़ाई: लाइन मोटाई चुनें।
  • पेन रंग: ड्रॉपडाउन या पिकर से रंग चुनें।
  • पेज नियंत्रण: पेज नेविगेट करें (लॉक मोड में स्वाइप)।
  • मल्टी-टच: 1-उंगली: ड्रॉ; 2-उंगली: मिटाएं; 3-उंगली: पूर्ववत; 4-उंगली: रैंडम रंग।

सामान्य

  • टैब स्विच करके पाठ और ड्राइंग के बीच वैकल्पिक करें।
  • सक्रिय टैब पर दोबारा टैप करके अनुभागों को संकुचित करें।
  • डेटा स्वचालित रूप से ब्राउज़र स्टोरेज में सहेजा जाता है।

ପାଠ ଲେଖନ ଅଂଶ (ଲେଖନ ଟ୍ୟାବ୍)

  • ପୂର୍ବବର୍ତ୍ତୀ: ଶେଷ ପାଠ ପରିବର୍ତ୍ତନକୁ ପୁନରୁଦ୍ଧାରଣ କରନ୍ତୁ।
  • ପୁନର୍ବାର: ଶେଷ ପୂର୍ବବର୍ତ୍ତୀ କାର୍ଯ୍ୟକୁ ପୁନରାବୃତ୍ତି କରନ୍ତୁ।
  • ଖୋଜିବା ଓ ପରିବର୍ତ୍ତନ: ପାଠ ଖୋଜନ୍ତୁ ଓ ପରିବର୍ତ୍ତନ କରନ୍ତୁ।
  • ସବୁ ଚୟନ: ପୂରା ପାଠ ଚୟନ କରନ୍ତୁ।
  • କପି: ଚୟନିତ ପାଠକୁ କ୍ଲିପବୋର୍ଡକୁ କପି କରନ୍ତୁ।
  • ପାଠ ମାରିବା: ସବୁ ପାଠ ସଫା କରନ୍ତୁ।
  • ପାଠ ସଂରକ୍ଷଣ: ବର୍ତ୍ତମାନର ପାଠକୁ ଏକ ଅନନ୍ୟ ଆଇଡି ସହିତ ସଂରକ୍ଷଣ କରନ୍ତୁ।
  • ସଂରକ୍ଷିତ ପାଠ: ସଂରକ୍ଷିତ ପାଠ ଦେଖନ୍ତୁ ଓ ଲୋଡ୍ କରନ୍ତୁ।
  • ସଂରକ୍ଷିତ ହରାଇବା: ସଂରକ୍ଷିତ ପାଠକୁ କୁଆରକୁ ପଠାନ୍ତୁ।
  • ପାଠ ପୁନରୁଦ୍ଧାରଣ: କୁଆରରୁ ପୁନରୁଦ୍ଧାରଣ କରନ୍ତୁ (60 ଦିନ ଭିତରେ)।
  • ସ୍ଥାୟୀ ହରାଇବା: କୁଆରରୁ ସ୍ଥାୟୀ ଭାବେ ହରାନ୍ତୁ।
  • ଫାଇଲ୍ ଖୋଲନ୍ତୁ: TXT କିମ୍ବା PDF ଲୋଡ୍ କରନ୍ତୁ (ପାଠ ନିଷ୍କାସନ କିମ୍ବା ଡ୍ରଅ ମୋଡ୍)।
  • ପାଠ ନିର୍ଯ୍ୟାସ: ବର୍ତ୍ତମାନର ପାଠକୁ TXT ଆକାରରେ ଡାଉନଲୋଡ୍ କରନ୍ତୁ।
  • ଆମକୁ ସହାୟତା କରନ୍ତୁ: UPI ମାଧ୍ୟମରେ ଦାନ କରନ୍ତୁ।

ଚିତ୍ରକଳା ଅଂଶ (ଡ୍ରଅ ଟ୍ୟାବ୍)

  • ଡ୍ରଅ: ଚିତ୍ରକଳା ମୋଡ୍ ଟଗଲ୍ କରନ୍ତୁ (ସ୍ମୁଥ୍ କର୍ଭ୍)।
  • ରବର୍: ରବର୍ ଟଗଲ୍ କରନ୍ତୁ (ରାଇଟ୍-କ୍ଲିକ୍ କିମ୍ବା 2-ଆଙ୍ଗୁଳି ଟଚ୍)।
  • ବକେଟ୍ ଫିଲ୍: ଅଞ୍ଚଳକୁ ଚୟନିତ ରଙ୍ଗରେ ଭରନ୍ତୁ।
  • ଲକ୍ ଭ୍ୟୁ: ଚିତ୍ରକଳା ଲକ୍ କରନ୍ତୁ (5-ଆଙ୍ଗୁଳି ଟଚ୍ ଟଗଲ୍)।
  • ରିସେଟ୍ ପଜ୍: କ୍ୟାନ୍ଭାସ୍ ଅବସ୍ଥାନ ରିସେଟ୍ କରନ୍ତୁ।
  • ନୂଆ ପୃଷ୍ଠା: ନୂଆ ଚିତ୍ରକଳା ପୃଷ୍ଠା ଯୋଡ଼ନ୍ତୁ।
  • ପୃଷ୍ଠା ସଫା: ବର୍ତ୍ତମାନର ପୃଷ୍ଠା ସଫା କରନ୍ତୁ (ଖାଲି ପୃଷ୍ଠା ହରାନ୍ତୁ)।
  • ପୂର୍ବବର୍ତ୍ତୀ/ପୁନର୍ବାର: ଚିତ୍ରକଳା କାର୍ଯ୍ୟକୁ ପୂର୍ବବର୍ତ୍ତୀ/ପୁନରାବୃତ୍ତି କରନ୍ତୁ।
  • JPG ସଂରକ୍ଷଣ: ବର୍ତ୍ତମାନର ପୃଷ୍ଠାକୁ JPG ଆକାରରେ ନିର୍ଯ୍ୟାସ କରନ୍ତୁ।
  • PDF ସେୟାର୍: ସବୁ ପୃଷ୍ଠାକୁ PDF ଆକାରରେ ନିର୍ଯ୍ୟାସ କରନ୍ତୁ।
  • ପେନ୍ ବେହଦ: ଲାଇନ୍ ଗଭୀରତା ଚୟନ କରନ୍ତୁ।
  • ପେନ୍ ରଙ୍ଗ: ଡ୍ରପ୍ଡାଉନ୍ କିମ୍ବା ପିକର୍ରୁ ରଙ୍ଗ ଚୟନ କରନ୍ତୁ।
  • ପୃଷ୍ଠା ନିୟନ୍ତ୍ରଣ: ପୃଷ୍ଠା ନେଭିଗେଟ୍ କରନ୍ତୁ (ଲକ୍ ମୋଡ୍ରେ ସ୍ୱାଇପ୍)।
  • ମଲ୍ଟି-ଟଚ୍: 1-ଆଙ୍ଗୁଳି: ଡ୍ରଅ; 2-ଆଙ୍ଗୁଳି: ମାରିବା; 3-ଆଙ୍ଗୁଳି: ପୂର୍ବବର୍ତ୍ତୀ; 4-ଆଙ୍ଗୁଳି: ରାଣ୍ଡମ୍ ରଙ୍ଗ।

ସାଧାରଣ

  • ଟ୍ୟାବ୍ ସ୍ୱିଚ୍ କରି ପାଠ ଓ ଚିତ୍ରକଳା ମଧ୍ୟରେ ବଦଳାନ୍ତୁ।
  • ସକ୍ରିୟ ଟ୍ୟାବ୍ରେ ପୁନର୍ବାର ଟ୍ୟାପ୍ କରି ଅଂଶଗୁଡ଼ିକୁ ସଙ୍କୁଚିତ କରନ୍ତୁ।
  • ଡାଟା ସ୍ୱୟଂଚାଳିତ ଭାବେ ବ୍ରାଉଜର୍ ଷ୍ଟୋରେଜ୍ରେ ସଂରକ୍ଷିତ ହୁଏ।
